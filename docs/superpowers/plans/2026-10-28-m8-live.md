# M8 Live Runner — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans.

**Goal:** Deliver the live trading loop that runs Mon–Fri during the London killzone (06:50–10:05 London), executes the tick→structure→setup→risk→gateway pipeline, tracks a state machine (IDLE→ARMED→IN_TRADE→MANAGED→CLOSED), and stops cleanly on a KILL sentinel or killzone end.

**Architecture:** APScheduler fires the killzone start/stop at exact London times. The loop polls ticks from `TradeGateway`, detects new 1m bar boundaries (by minute timestamp change), then fetches fresh rates for all four TFs (D1/H4/M15/M1) in one call per TF via `gateway.rates()`. Structure analysis, setup evaluation, news blackout, and risk check run sequentially. Orders go through `TradeGateway.order_send`. An `Alerter` Protocol (with `NullAlerter` stub) decouples alerting from M9. Position reconciliation on ARMED entry handles process restarts.

**Tech Stack:** Python 3.11+, `apscheduler>=3.10`, `pandas>=2.2`, `pydantic`, `structlog`, `zoneinfo`.

**Spec:** `docs/SPEC.md` §7 M8, §6.6 (perf), §6.7 (testing), §6.8 (observability stubs), §6.9 (boundaries).

```python
from __future__ import annotations

from datetime import datetime

import pandas as pd

from v17.common.dtos import Bar, Tick
from v17.common.types import TF, Symbol
from v17.mt5.protocol import TradeGateway

_REQUIRED_TFS: tuple[TF, ...] = (TF.D1, TF.H4, TF.M15, TF.M1)
_BARS_LOOKBACK: int = 200
_MIN_BARS: int = 20


def bars_to_df(bars: list[Bar]) -> pd.DataFrame:
    return pd.DataFrame(
        [
            {
                "ts": pd.Timestamp(b.ts),
                "open": float(b.open),
                "high": float(b.high),
                "low": float(b.low),
                "close": float(b.close),
                "volume": b.volume,
            }
            for b in bars
        ]
    )


class BarBuilder:
    """Detects new 1m bar boundaries and fetches fresh rates for all TFs."""

    def __init__(self, symbol: Symbol) -> None:
        self._symbol = symbol
        self._last_m1_ts: datetime | None = None

    def on_tick(
        self, tick: Tick, gateway: TradeGateway
    ) -> dict[TF, pd.DataFrame] | None:
        bar_minute = tick.ts.replace(second=0, microsecond=0)
        if self._last_m1_ts is None:
            self._last_m1_ts = bar_minute
            return None
        if bar_minute <= self._last_m1_ts:
            return None
        self._last_m1_ts = bar_minute
        result: dict[TF, pd.DataFrame] = {}
        for tf in _REQUIRED_TFS:
            bars = gateway.rates(self._symbol, tf, _BARS_LOOKBACK)
            if len(bars) < _MIN_BARS:
                return None
            result[tf] = bars_to_df(bars)
        return result
```

```python
from __future__ import annotations

from dataclasses import dataclass, field
from pathlib import Path

from v17.common.clock import Clock
from v17.common.types import Symbol
from v17.data.ports import CalendarProvider
from v17.live.kill_switch import read_kill
from v17.mt5.protocol import TradeGateway

_GATE_FILE = "GATE_PASSED"


@dataclass(frozen=True)
class PreFlightResult:
    ok: bool
    reasons: list[str] = field(default_factory=list)


class PreFlight:
    def __init__(
        self,
        state_root: Path,
        gateway: TradeGateway,
        calendar: CalendarProvider,
        symbol: Symbol,
        clock: Clock,
    ) -> None:
        self._state_root = state_root
        self._gateway = gateway
        self._calendar = calendar
        self._symbol = symbol
        self._clock = clock

    def run(self) -> PreFlightResult:
        reasons: list[str] = []

        if not (self._state_root / _GATE_FILE).exists():
            reasons.append("GATE_PASSED sentinel missing — run 'v17 validate' first")

        if read_kill(self._state_root):
            reasons.append("KILL sentinel active — clear it before starting")

        try:
            t = self._gateway.tick(self._symbol)
            if t is None:
                reasons.append(f"MT5 tick returned None for {self._symbol}")
        except Exception as exc:
            reasons.append(f"MT5 tick failed: {exc}")

        try:
            now = self._clock.now()
            self._calendar.events(now, now)
        except Exception as exc:
            reasons.append(f"calendar not available: {exc}")

        return PreFlightResult(ok=len(reasons) == 0, reasons=reasons)
```

**Interfaces:**
- Consumes: all prior live modules + `StructureEngine` (M2), `SetupEngine` (M3), `RiskEngine` (M4), `TradeGateway` (M7), `CalendarProvider` (M1), `Alerter` (Task 1), `Clock` (common)
- Produces: `LiveRunner` class with `start()` (blocking), `stop()`, `_killzone_start()`, `_killzone_stop()`, `_tick_step(symbol)`, `state` property

**State machine transitions:**
- `IDLE` → `PRE_FLIGHT` → `ARMED`: on `_killzone_start()` when pre-flight passes
- `IDLE`: on `_killzone_start()` when pre-flight fails (log + alert, stay IDLE)
- `ARMED` → `IN_TRADE`: on signal + risk allow + order_send ok
- `IN_TRADE`/`MANAGED` → `ARMED`: on trade close detected (position gone from gateway)
- `ARMED` → `IDLE`: on `_killzone_stop()` or KILL sentinel detected
- Any state → `IDLE`: KILL sentinel

**Position reconciliation** in `_reconcile()`: call `gateway.positions()`, if any position with matching symbol exists → set `_open_trade` from position data + set state to `IN_TRADE`.

**Tick step pipeline** (called in `_run_loop`):
1. Check `read_kill(state_root)` → if True: go IDLE, alert, break
2. Get `tick = gateway.tick(symbol)` → if None: continue
3. If state == ARMED:
   a. Check news blackout: `calendar.is_blackout(symbol, tick.ts)` → if True: continue
   b. `bars = bar_builder.on_tick(tick, gateway)` → if None: continue
   c. `snap = structure_engine.analyze(bars)` (catch `V17StructureError` → log, continue)
   d. For each setup engine: `signal = engine.evaluate(snap, tick.ts, bars[TF.M1])`
   e. If signal: `decision = risk_engine.check(signal, account)` → if not allow: log, continue
   f. Build `OrderRequest`, call `gateway.order_send(order)` → if not ok: log, continue
   g. Record open trade, update account via `risk_engine.on_fill(trade, account)`, set IN_TRADE, alert
   h. Break (one trade at a time)
4. If state in (IN_TRADE, MANAGED):
   a. `positions = gateway.positions()`
   b. If `_open_trade.ticket` not in position tickets → trade closed, call `risk_engine.on_close`, set ARMED, alert

```python
from __future__ import annotations

import structlog
from decimal import Decimal
from pathlib import Path

from v17.common.clock import Clock
from v17.common.dtos import (
    AccountState,
    OrderRequest,
    Position,
    Trade,
)
from v17.common.errors import V17KillSwitchActive, V17StructureError
from v17.common.types import TF, Side, Symbol, Ticket
from v17.data.ports import CalendarProvider
from v17.live.alerter import Alerter
from v17.live.bar_builder import BarBuilder
from v17.live.kill_switch import read_kill
from v17.live.preflight import PreFlight
from v17.live.state_machine import RunnerState
from v17.mt5.protocol import TradeGateway
from v17.risk.ports import RiskEngine
from v17.setups.ports import SetupEngine
from v17.structure.ports import StructureEngine

_log = structlog.get_logger(__name__)


class LiveRunner:
    def __init__(
        self,
        gateway: TradeGateway,
        structure_engine: StructureEngine,
        setup_engines: list[SetupEngine],
        risk_engine: RiskEngine,
        calendar: CalendarProvider,
        alerter: Alerter,
        state_root: Path,
        symbols: list[Symbol],
        clock: Clock,
        initial_account: AccountState,
    ) -> None:
        self._gateway = gateway
        self._structure_engine = structure_engine
        self._setup_engines = setup_engines
        self._risk_engine = risk_engine
        self._calendar = calendar
        self._alerter = alerter
        self._state_root = state_root
        self._symbols = symbols
        self._clock = clock
        self._account = initial_account
        self._state = RunnerState.IDLE
        self._open_trade: Trade | None = None
        self._bar_builders: dict[Symbol, BarBuilder] = {
            sym: BarBuilder(sym) for sym in symbols
        }
        self._running = False

    @property
    def state(self) -> RunnerState:
        return self._state

    # ------------------------------------------------------------------ #
    # APScheduler entry points                                              #
    # ------------------------------------------------------------------ #

    def _killzone_start(self) -> None:
        self._state = RunnerState.PRE_FLIGHT
        pf = PreFlight(
            self._state_root,
            self._gateway,
            self._calendar,
            self._symbols[0],
            self._clock,
        )
        result = pf.run()
        if not result.ok:
            for r in result.reasons:
                _log.error("preflight_failed", reason=r)
            self._alerter.send(f"PreFlight FAILED: {'; '.join(result.reasons)}", level="error")
            self._state = RunnerState.IDLE
            return
        self._state = RunnerState.ARMED
        self._reconcile()
        _log.info("killzone_armed")
        self._alerter.send("Killzone ARMED — listening for setups")

    def _killzone_stop(self) -> None:
        _log.info("killzone_stop")
        self._alerter.send("Killzone END — going idle")
        self._state = RunnerState.IDLE

    # ------------------------------------------------------------------ #
    # Run loop (called externally in tests; blocking in start())            #
    # ------------------------------------------------------------------ #

    def start(self) -> None:
        from apscheduler.schedulers.blocking import BlockingScheduler
        from apscheduler.triggers.cron import CronTrigger

        _LONDON = "Europe/London"
        self._running = True
        scheduler = BlockingScheduler(timezone=_LONDON)
        scheduler.add_job(
            self._killzone_start,
            CronTrigger(day_of_week="mon-fri", hour=6, minute=50, timezone=_LONDON),
        )
        scheduler.add_job(
            self._killzone_stop,
            CronTrigger(day_of_week="mon-fri", hour=10, minute=5, timezone=_LONDON),
        )
        try:
            scheduler.start()
        except (KeyboardInterrupt, SystemExit):
            pass

    def stop(self) -> None:
        self._running = False
        self._state = RunnerState.IDLE

    # ------------------------------------------------------------------ #
    # Per-tick step                                                         #
    # ------------------------------------------------------------------ #

    def _tick_step(self, symbol: Symbol) -> None:
        if read_kill(self._state_root):
            _log.critical("kill_switch_detected")
            self._alerter.send("KILL sentinel detected — going IDLE", level="critical")
            self._state = RunnerState.IDLE
            return

        tick = self._gateway.tick(symbol)
        if tick is None:
            return

        if self._state == RunnerState.ARMED:
            self._process_armed(symbol, tick)
        elif self._state in (RunnerState.IN_TRADE, RunnerState.MANAGED):
            self._process_in_trade(symbol, tick)

    def _process_armed(self, symbol: Symbol, tick: object) -> None:
        from v17.common.dtos import Tick as _Tick
        assert isinstance(tick, _Tick)

        if self._calendar.is_blackout(symbol, tick.ts):
            return

        bars = self._bar_builders[symbol].on_tick(tick, self._gateway)
        if bars is None:
            return

        try:
            snap = self._structure_engine.analyze(bars)
        except V17StructureError as exc:
            _log.warning("structure_error", error=str(exc))
            return

        bars_1m = bars[TF.M1]
        for engine in self._setup_engines:
            signal = engine.evaluate(snap, tick.ts, bars_1m)
            if signal is None:
                continue

            decision = self._risk_engine.check(signal, self._account)
            if not decision.allow:
                _log.info("risk_rejected", code=decision.code, reason=decision.reason)
                continue

            assert decision.size_lots is not None
            order = OrderRequest(
                symbol=signal.symbol,
                side=signal.side,
                size_lots=decision.size_lots,
                sl=signal.sl,
                tp=signal.tp,
                comment=f"{signal.setup}:{signal.id}",
            )
            result = self._gateway.order_send(order)
            if not result.ok:
                _log.error(
                    "order_rejected",
                    code=result.error_code,
                    msg=result.error_message,
                )
                continue

            assert result.ticket is not None
            assert result.filled_price is not None
            assert result.filled_at is not None
            trade = Trade(
                ticket=result.ticket,
                signal_id=signal.id,
                symbol=signal.symbol,
                side=signal.side,
                size_lots=decision.size_lots,
                entry=result.filled_price,
                sl=signal.sl,
                tp=signal.tp,
                opened_at=result.filled_at,
            )
            self._open_trade = trade
            self._account = self._risk_engine.on_fill(trade, self._account)
            self._state = RunnerState.IN_TRADE
            _log.info(
                "trade_opened",
                setup=signal.setup,
                side=signal.side.value,
                symbol=str(signal.symbol),
                entry=str(result.filled_price),
                ticket=result.ticket,
            )
            self._alerter.send(
                f"ENTRY {signal.setup} {signal.side} {signal.symbol} @{result.filled_price} "
                f"SL={signal.sl} TP={signal.tp}"
            )
            break  # one trade at a time

    def _process_in_trade(self, symbol: Symbol, tick: object) -> None:
        if self._open_trade is None:
            self._state = RunnerState.ARMED
            return

        positions = self._gateway.positions()
        open_tickets = {p.ticket for p in positions}

        if self._open_trade.ticket not in open_tickets:
            from v17.common.dtos import Tick as _Tick
            assert isinstance(tick, _Tick)
            closed = self._open_trade.model_copy(
                update={"closed_at": tick.ts, "reason": "sl_or_tp"}
            )
            self._account = self._risk_engine.on_close(closed, self._account)
            _log.info(
                "trade_closed",
                ticket=self._open_trade.ticket,
                symbol=str(self._open_trade.symbol),
            )
            self._alerter.send(f"CLOSE {self._open_trade.symbol} ticket={self._open_trade.ticket}")
            self._open_trade = None
            self._state = RunnerState.ARMED

    # ------------------------------------------------------------------ #
    # Position reconciliation                                               #
    # ------------------------------------------------------------------ #

    def _reconcile(self) -> None:
        positions = self._gateway.positions()
        for pos in positions:
            if pos.symbol in self._symbols:
                from v17.common.types import SignalId
                self._open_trade = Trade(
                    ticket=pos.ticket,
                    signal_id=SignalId("reconciled"),
                    symbol=pos.symbol,
                    side=pos.side,
                    size_lots=pos.size_lots,
                    entry=pos.entry,
                    sl=pos.sl,
                    tp=pos.tp,
                    opened_at=pos.opened_at,
                )
                self._account = self._account.model_copy(
                    update={"open_positions": 1}
                )
                self._state = RunnerState.IN_TRADE
                _log.info("reconciled_open_trade", ticket=pos.ticket, symbol=str(pos.symbol))
                return
```
