# M5a Backtest Perf Tune — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans.

**Goal:** Cut the per-1m-bar snapshot cost so the full 12-year EURUSD + GBPUSD backtest finishes in ≤ 15 minutes wall clock (SPEC §6.6 performance target), without changing produced trades on a fixed-seed slice. Current MVP runs ~11s/day of 1m bars (≈ 16 h for 12 years). Target: ≤ 1s/day.

**Architecture:** Shift all O(n) work into the `precompute` step, done once per slice. Rewrite `snapshot_at` so it does only O(log n) filters + constant-time lookups over precomputed indexes. Setup engines unchanged (interfaces stable).

**Tech Stack:** Python 3.11+, pandas, numpy.

**Spec:** `docs/SPEC.md` §6.6, §7 M2+M5; `docs/API.md`; relevant ADRs (0001, 0005).
